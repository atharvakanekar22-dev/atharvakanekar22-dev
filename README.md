## 02 / SELECTED WORK

Projects are where ideas meet implementation.

### 01. 空 — Khali-Jagah

**AI-powered Mumbai local-train crowd intelligence**

An Android application concept focused on helping commuters make more informed travel decisions through coach-level crowd information and AI-generated travel insights.

**What I've built**
- Android interface using Kotlin, Jetpack Compose, and Material 3.
- Node.js and Express backend with train, station, and coach crowd data.
- AI-powered crowd analysis using Google's GenAI SDK and Gemma model.
- REST API integration, structured JSON responses, and a rule-based fallback when AI is unavailable.

**Stack:** `Kotlin` · `Jetpack Compose` · `Node.js` · `Express` · `Gemma` · `REST APIs`

[Repository](https://github.com/atharvakanekar22-dev/REPLACE_WITH_KHALI_JAGAH_REPO_NAME)
